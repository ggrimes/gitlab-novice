# Introduction to Git and GitLab

A hands-on [Carpentries-style](https://carpentries.org/) lesson introducing
version control with Git and GitLab. It is built with
[The Carpentries Workbench][workbench] and developed in the
[Carpentries Incubator](https://carpentries-incubator.org/).

**Lesson website:** <https://ggrimes.github.io/gitlab-novice/>

**Status:** beta. The lesson has been taught at the University of Edinburgh
and is still being refined. Feedback from learners and other instructors is
very welcome.

## Who the lesson is for

Researchers, analysts and postgraduate students who work with data and code but
have not used version control before. It is usually taught as the final
workshop of a two-week Introduction to Data Science programme at the University
of Edinburgh, in a hybrid setting. See the
[learner profiles](https://ggrimes.github.io/gitlab-novice/profiles.html) for
more detail.

The setup uses University of Edinburgh services (ECDF GitLab, the Eddie
cluster and Noteable). Learners without a University login can use
[gitlab.com](https://gitlab.com) instead.

## Episodes

1. Why Version Control?
2. Configuring Git
3. Recording Changes Locally
4. Working with Remote Repositories
5. Using Git with a Graphical User Interface (RStudio)
6. Collaborating
7. Exploring History
8. Ignoring Things
9. Branching and Tagging
